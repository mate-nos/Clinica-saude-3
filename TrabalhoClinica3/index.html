Painel do Desenvolvedor: Explicando o JSON

1. O que é JSON?

JSON (JavaScript Object Notation) é um padrão de troca de dados baseado na notação de objetos da linguagem Javascript. É um formato usado para a representação de dados estruturados, visando uma linguagem comum para diversas linguagens de programação pelos mais diversos protocolos (como o HTTP). Ele retorna valores especificamente em chave-valor, em que cada chave identifica uma informação e o valor armazena o dado correspondente.

2. Como a requisição funciona no navegador?

A requisição neste contexto funciona por meio da chamada da função fetch(), que realiza uma requisição http para servidores externos (como a API ViaCEP). Essa requisição funciona de maneira assincrona (ou seja, sem parar a execução do restante do app nem recarregar o restante da página).

3. Como o JavaScript utiliza a resposta?

Neste contexto, fazemos o uso do javascript para modificar nossos campos e verificar, dentro do código, a validade do CEP. Fazemos isso por meio do método .json(), que transforma a resposta recebida da API em notação JSON em um objeto javascript, de modo a permitir o acesso aos atributos especificados pela repsosta fornecida.
